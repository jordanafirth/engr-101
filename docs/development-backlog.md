## Lesson package definition

A teachable lesson package includes objectives, the preflight and answer feedback, required materials/setup, a two-hour teaching plan, student prompts or worksheets, worked examples or instructor notes, the expected evidence, and any assessment rubric. Identify source adaptations and verify calculations. Pair technical tasks with individual interpretation so student learning remains visible despite group project work.
